# AUR Studio 설치 안내

## 받기
- AUR Studio: https://github.com/yoosungbo/aur-studio-releases/releases/latest
- AUR Studio Edu(수업용): https://github.com/yoosungbo/aur-studio-edu-releases/releases/latest

`…Setup-버전.exe` 파일 하나만 받으면 됩니다. 같은 페이지의 `.blockmap`, `latest.yml`은 자동 업데이트용이라 받지 않아도 돼요.

## 설치할 때 "Windows의 PC 보호" 창이 뜨면
아직 코드 서명 인증서가 없는 앱이라 Windows가 처음 보는 프로그램으로 알려 줍니다.

1. 창의 **추가 정보**를 누릅니다.
2. 아래에 생긴 **실행** 버튼을 누릅니다.

"스마트 앱 컨트롤이 이 앱을 차단했습니다"처럼 **실행 버튼이 없는 창**이 뜨면 보안 설정을 끄지 말고 알려 주세요(수업용은 강사에게).

## 필요한 것
- Windows 10/11 64비트
- 여유 공간: 앱 약 450MB. 로컬 AI(목소리·효과음 엔진)를 설치하면 엔진마다 수 GB가 더 필요해요. 10GB 이상 비워 두기를 권해요.
- 인터넷 연결

## 수업용(Edu)
- 처음 열면 강사에게 받은 **시리얼 번호**를 넣습니다.
- 일반 AUR Studio와 따로 설치되고, 서로의 자료를 건드리지 않아요.

## 업데이트
새 버전이 나오면 왼쪽 메뉴 아래에 **업데이트** 버튼이 생깁니다. 누르면 받고, **재시작**을 누르거나 앱을 닫으면 설치돼요. 만든 자료와 설정은 그대로 남습니다.
